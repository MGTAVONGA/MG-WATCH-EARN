# MG TECH Privacy Policy — Draft

**Status:** Draft for legal review. Replace the operator/contact details and have this reviewed for the countries where the service will operate before public launch.

MG TECH account data in this MVP includes the email address, display name, password hash, account creation time and learning progress. Passwords are not stored in plain text. The local MVP stores data in an SQLite database on the machine hosting the service.

This MVP does not currently send account data to an external AI provider, process payments, perform live target scanning, or provide email verification/password recovery. Do not enter sensitive personal information or passwords used on other services into training fields.

For a public service, the operator must publish a contact address, lawful basis and purposes for processing, retention periods, data-subject rights, hosting/processor details, international transfer information, cookie/session details, security incident process and complaint route. Users should be able to request access, correction and deletion. Define a retention and backup deletion schedule before launch.
